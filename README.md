# yarddock

Yard and reshape dock text streams with deterministic transforms.

**Site:** https://theworker02.github.io/yarddock/

## Install / run

```bash
git clone https://github.com/theworker02/yarddock.git
cd yarddock
node src/cli.js
node --test
```
